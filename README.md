# SIMPLE-PASSWORD-GENERATOR-PYTHON
-----Password Generator (Python)------

Description:

This is a simple password generator project built using Python.
It allows users to create secure passwords based on their preferences.

 Features:

- Generate password of any length
- Choose character types:
  - Letters (A-Z, a-z)
  - Digits (0-9)
  - Symbols (@#$% etc.)
- Supports all combinations (letters, digits, symbols)
- Clean and beginner-friendly code

 How to Run:

1. Install Python
2. Download or clone this repository
3. Open terminal / command prompt
4. Run the file:

python password_generator.py

Example:

===  PASSWORD GENERATOR ===
Enter length: 6

Letters? (y/n): y
Digits? (y/n): n
Symbols? (y/n): y

Password: a@K#pL

Purpose:

This project is created for learning Python basics like:

- random module
- string handling
- user input
